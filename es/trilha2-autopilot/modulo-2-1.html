TU VOZ · CUALQUIER PLATAFORMA · PUBLICACIÓN AUTOMÁTICA

Este es el sistema del video. Un archivo de voz de marca + un prompt adaptable, y el asistente te entrevista (tres preguntas), investiga qué está funcionando hoy en tu plataforma, escribe la publicación con tu voz y la programa mediante tu herramienta de publicación conectada. Tú solo la apruebas.

Antes de empezar (~10 minutos, una sola vez)

Asistente de código instalado y con sesión iniciada → claude.com/claude-code (la aplicación web del asistente también funciona: solo envía tu archivo de voz de marca al chat)

Tu archivo de voz de marca: toma la plantilla que viene con este paquete (brand-voice-template.md), complétala o deja que el Prompt 1 la cree por ti

Opcional — publicación automática: un MCP de publicación como Blotato conectado al asistente de código (blotato.com → clave de API → guía MCP de ellos → conecta tus redes sociales). ¿Sin MCP? El asistente te da publicaciones listas para copiar y pegar. Pregúntale al asistente de código: "list my connected MCP tools"

Opcional — imágenes con IA: el MCP Higgsfield para imágenes y Reels (higgsfield.ai)
