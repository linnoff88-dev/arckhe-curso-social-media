SUA VOZ · QUALQUER PLATAFORMA · PUBLICAÇÃO AUTOMÁTICA

Este é o sistema do vídeo. Um arquivo de voz da marca + um prompt adaptativo, e o assistente entrevista você (três perguntas), pesquisa o que está funcionando na sua plataforma hoje, escreve a publicação na sua voz — e agenda-a através da sua ferramenta de postagem conectada. Você apenas aprova.

Antes de começar (~10 minutos, uma vez)

Assistente de código instalado e logado → claude.com/claude-code (o app web do assistente também funciona — apenas envie seu arquivo de voz da marca para o chat)

Seu arquivo de voz da marca — pegue o modelo que vem com este pacote (brand-voice-template.md), preencha-o, ou deixe o Prompt 1 construí-lo para você

Opcional — postagem automática: um MCP de postagem como Blotato conectado ao assistente de código (blotato.com → chave de API → guia MCP deles → conecte suas redes sociais). Sem MCP? O assistente fornece publicações prontas para copiar e colar. Pergunte ao assistente de código: "list my connected MCP tools"

Opcional — visuais com IA: o MCP Higgsfield para imagens e Reels (higgsfield.ai)
