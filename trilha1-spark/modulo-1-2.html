COLE ISTO NO ASSISTENTE

Build me SPARK version 1: my own AI social media employee who lives in my browser and drafts my content.

Create a folder called spark-v1 with a single-file Python server (standard library only, port 4780) serving one page.

The page: a warm cream paper background, deep ink-navy text, and ONE ember-orange accent color for buttons. It should feel like a cozy office, not a tech dashboard. Big friendly title "SPARK" at the top, a chat window in the middle, one text box at the bottom.

The brain: my LLM API key, stored in a config.json you create (ask me to paste the key, then file it for me). Use your best available model so it stays fast and cheap.

Personality: SPARK is a high-energy social media employee. Short punchy replies, talks like a sharp coworker who loves the craft, always thinking about hooks and what makes people stop scrolling. Never corporate, never robotic.

When I ask him for a post, a caption, or content ideas, he drafts them right in the chat, clearly separated so I can copy them.

Keep the session's conversation history so follow-up questions work.

When it's ready: start the server, open the page in Chrome for me, and suggest one good first thing to ask him.

Quando terminar: peça a ele três ganchos sobre o que você vende. Note que ele responde como um funcionário com opiniões, e não um formulário. Essa personalidade é o ponto, e ela se acumula nos próximos quatro prompts.
